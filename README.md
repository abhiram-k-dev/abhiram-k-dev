### 🚀 Featured Projects

#### 🧬 [ProjectDNA](https://github.com/abhiram-k-dev/projectdna) — Autonomous Multi-Agent Software Engineering Framework
*Autonomous pipeline transforming `.dna` specifications into tested and deployed software.*
- **Architecture**: 6 specialized agents (Interview, Validator, Planner, Builder, Eval, Deployment) orchestrated with Google ADK patterns and A2A messaging.
- **Context Slicing**: Slices relevant sections for each agent, achieving **70%–90% token reduction**.
- **Zero-Trust Guardrails**: 6 blocking pre-hooks enforcing secret detection, tool permissions, scope limits, and eval gating.
- **MCP Servers**: Simulated in-process Filesystem, GitHub, Docker, and Database servers.

#### 📄 [Doc2Data AI](https://github.com/abhiram-k-dev/Doc2Data-AI) — AI Document Data Extraction Platform
*Web app extracting structured data from document images using dual-LLM pipelines.*
- Extracts tables, key-value pairs, attendance registers, and forms from images via **Gemini 2.5 Flash** with fallback to **Groq Llama 4 Scout**.
- Two-pass pipeline with image preprocessing, coordinate-aware parsing, and JSON self-repair. Built with Flask + Python.

#### 🌾 [Vyapaar Mitra](https://github.com/abhiram-k-dev/vyapaar-mitra) — Rural Decision Support & Alternative Credit Scoring
*Local-first, privacy-respecting financial modeling for micro-entrepreneurs.*
- Combines deterministic causal financial modeling, 4-pillar alternative credit scoring, Bahi-Khata ledger tracking, government scheme matching, and bounded AI advisory.

#### 🎙️ [MeetMind](https://github.com/abhiram-k-dev/MeetMind) — Context-Aware AI Meeting Intelligence Agent
*Enterprise AI agent built at the Agents League Hackathon.*
- Converts meeting audio transcripts into structured decision logs, assigned action items, and draft follow-up emails using Work IQ-style context retrieval with Gemini.

#### 💡 [BizBrain](https://github.com/abhiram-k-dev/BizBrain) — Real-Time AI Business Intelligence Dashboard
*Built at Vibe Coding Hackathon 2026.*
- Full-stack React + Node.js/Express application with real-time Server-Sent Events (SSE) chat powered by **LLaMA 3.3 70B** for SWOT analyses, competitor profiling, and strategy roadmaps.
