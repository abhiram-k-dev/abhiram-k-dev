### 🚀 Featured Projects

**[Doc2Data AI](https://github.com/abhiram-k-dev)** — AI-powered document data extraction platform
Flask web app extracting structured data (tables, key-value pairs, attendance registers) from document images via Gemini 2.5 Flash, with a dual-AI fallback to Groq's Llama 4 Scout.

Built at the Agents League Hackathon (Enterprise Agents track). Converts meeting transcripts into a decision log, action items, and drafted follow-up emails using Gemini.

**[BizBrain](https://github.com/abhiram-k-dev)** — AI business intelligence agent
Built at Vibe Coding Hackathon 2026. React + Node.js/Express app with real-time SSE chat powered by LLaMA 3.3 70B, generating SWOT analysis, competitor profiling, and roadmaps.
